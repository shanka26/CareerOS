# CareerOS

CareerOS is an AI career operating system that turns verified career knowledge into explainable, versioned application materials.

The repository is being implemented milestone-by-milestone from the [Master Implementation Charter](./CareerOS_Master_Implementation_Charter.md). See [the implementation plan](./docs/IMPLEMENTATION_PLAN.md) for current status, decisions, acceptance criteria, and risks, and [the development guide](./docs/DEVELOPMENT.md) for local setup.
